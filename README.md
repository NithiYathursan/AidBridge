# 🌍 AidBridge: Disaster Relief & Donation Management System

**AidBridge** is a PHP + MySQL web platform designed to connect **victims, donors, NGOs, and admins** during disaster situations in Sri Lanka.  
It helps manage **aid requests, donations, resource distribution, and reports** in one transparent system.

## 🚀 Key Features
- 👤 Role-based login (Admin, Donor, NGO, Victim)  
- 🌪 Submit and track disaster aid requests  
- 💰 Manage donations (cash or goods)  
- 📦 Resource allocation and delivery tracking  
- 🔔 Real-time notifications and status updates  
- 📊 Analytics dashboard and PDF/CSV reports  
- 🗺 Integrated Google Map for location-based requests  

## ⚙️ Tech Stack
**Frontend:** HTML, CSS, Bootstrap, JS  
**Backend:** PHP (XAMPP/WAMP)  
**Database:** MySQL  
**Visualization:** Chart.js, Google Maps API
